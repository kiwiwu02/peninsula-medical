# 图纸页码 146 Stage 2 Clean 解析

## 页面功能

本页为 M-HOUSE DISTRIBUTION CIRCUIT 的应急灯插座与面板灯供电页。上方 AC380/220V 母线分出两路 AC220V 支路，分别用于应急灯插座和面板灯。

## 电源与页间连续

`R2700/S2700/T2700/02100` 从 `145-25` 进入，分支供电后继续到 `151-1`。本页仅使用 `R2700/02100` 与 `S2700/02100` 两组单相回路，`T2700` 只作为母线连续。

## 主要设备与产品引用

`1461MCB` 和 `1462MCB` 均为 `iC65N 2P C10` 两极断路器。应急灯插座负载框归属 `(91) 机房配电柜`；面板灯支路在本页以图纸位置箭头引出。

## 支路链路

| 支路 | 输入与器件 | 输出与负载 |
| --- | --- | --- |
| 应急灯插座 | `R2700/02100 -> 1461MCB 1/3 -> 2/4` | `R14601/O14601 -> EMERGENCY LIGHT OUTLET AC220V 4.5W x 6`，归属 `(91) 机房配电柜` |
| 面板灯 | `S2700/02100 -> 1462MCB 1/3 -> 2/4` | `S14602/O14602 -> 196-2 PANEL LIGHT AC220V` |

## 输入输出与端子

两只 MCB 均以 `1/3` 为输入端、`2/4` 为输出端。`1461MCB` 输出进入本页应急灯插座负载框；`1462MCB` 输出不在本页落负载，而是以 `S14602/O14602` 延续到 `196-2`。

## 页间引用

本页母线来源位置为 `145-25`，去向位置为 `151-1`。面板灯支路外接位置为 `196-2`。

## 边界与未决事项

`1461MCB`、`1462MCB`、应急灯插座负载框、面板灯外接箭头和上方母线连续均为独立边界。未决事项：无。
