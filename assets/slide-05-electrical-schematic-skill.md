# 浦东起重机电气原理图解析

只用 `electrical_schematic_kb` 的逐页 Markdown 正文作为电气事实证据；图纸定位结果只可提供链接。所有结论必须对应题干设备，不得用同类设备或通用电气知识补全。此 skill 的结果也可作为组合工具 `diagnose_equipment_fault` 中 `electrical_schematic_interpreter` 证据字段的内容。

设备号为首次检索的必填条件。缺失时只回复：`请选择设备号：801、804、805、806、807、808、809、813、814、815、816、817、818、821、833、834、836、837、853、854。` 同一会话可继承最近一次明确且未变更的设备号；多个候选无法消歧时使用同一提示。

## 检索流程与限制

使用本 skill 的 `run_skill_cli` 执行：`python3 scripts/search_schematic.py search --device <设备号> --question "<用户原问题>"`。用户明确图页时额外传 `--drawing <图页>`。读取 JSON 中的 `dataset`、`selected_files` 与 `diagnostics`，再对 **全部** `selected_files` 执行一次 `pack`，每个文件各传一个 `--file`，并传入同一个 `--device`，例如：`pack --dataset <dataset> --device <设备号> --file <文件1> --file <文件2> --question "<用户原问题>"`。只以 pack 返回的逐页 Markdown 正文和 `sources` 作为电气事实证据；回答前必须读取其 `claim_contract`，按其中的已证实、需现场确认、资料不能单独证明三类边界组织结论。若 `evidence_complete=false` 或任一 `sources[].content_truncated=true`，不能把本次 pack 当作完整证据；优先缩小到相关页重新 pack，必要时提高 `--max-chars`，无法补齐时明确证据缺口。`required_follow_ups` 非空时，必须逐项加载所列 skill 并以给出的 `query` 执行其 CLI，完成后才能作答。

- 检索脚本会一次提交完整功能短语及其子短语（或完整位号、PLC 地址），无需也不得由模型把问题改写成多个词反复调用。
- 首轮无直接命中时立即说明证据不足并追问；首轮只有弱匹配时，脚本最多基于命中正文中真实出现的位号或明确跨页引用补查一次。禁止按页码顺序枚举、递增/递减扫描或凭猜测逐页重试。
- `drawing` 仅可使用用户明确图页，或下述已取证跨页追溯中的明确引用图页；模型不得自行构造页码。
- 当首个 `pack` 的正文或 `follow_up_references` 明确给出跨页位置，且该跨页是回答题干所需的连接、控制或因果链的一环时，必须继续解析该页：以该引用中的图页执行一次 `search --drawing <图页>`，再对返回的选中页执行 `pack`。尤其当前页仅以“跨页位置 + 线号/PLC 地址/模块位号”摘要控制输出，而目标页承载该输出的端子、模块、功能或执行对象时，即使摘要已出现，也必须解析目标页。此为已取证跨页追溯，不属于凭猜测扩展检索。每条题干链路最多补查两页；跨页正文已覆盖题干时立即停止。
- 若跨页正文取得 801 的 `IB`、`OB`、`MB` 或 `SB` 地址，而用户询问原因、触发条件、跳闸、动作或程序逻辑，必须加载 `pd-yaskawa-ladder-graph-rg` 并以该地址运行其 CLI；`pack.claim_contract.required_follow_ups` 是该义务的机器可读清单，不得省略。硬件连接事实仍只来自本 skill 的 `pack`，程序条件和上游路径只来自梯形图结果。对输入无信号或反馈异常题，若 `claim_contract.required_answer_slices` 非空，答案至少分别覆盖反馈链、执行/动作链、来源明确的并列控制支路和现场确认边界；不能只复述 PLC 输入页的末端信息。
- 候选多义、正文未覆盖或资料缺失时，明确追问位号、图页、设备标识、线号或端子，不得跨设备或凭常识补全。
- 一般情况下，一次工具结果已覆盖题干字段即停止，不为“可能相关”扩展背景页或同类设备资料；但对原因、动作异常、输入无信号或反馈异常题，若 `claim_contract.required_answer_slices` 非空，必须完成其中的链路覆盖后才能停止。这里的“覆盖”只要求保留题干相关且正文明确支持的节点，不要求抄录整页无关器件。
- 对用户给出的具体电气标识（位号、PLC 地址、线号或端子）必须将用户原话仅执行一次上述检索流程。若无直接证据，只能说明该标识在当前设备图纸正文中未找到，并追问该标识来自 HMI、PLC 程序、图纸还是工单；不得改写为其他地址或功能词重复检索，不得调用知识库、PLC、放线表或工单来猜测含义。
- 本 skill 只解释原理图正文中的硬件接线事实；不得推断程序逻辑、触点/线圈的执行条件、置位条件或上游路径。若因题干需要而在跨页追溯中取得具体 801 PLC 地址，加载梯形图 skill 取得该部分证据；否则明确程序逻辑未确认。原理图地址写法和梯形图规范地址如有差异，必须分别保留原文并标注映射关系或“需人工核对”，不得静默改写；同理，不得把原始触点类型字段直接翻译成相反的现场状态。
- 元件型号、附件缩写、反馈触点和继电器链只能按正文明确标注解释：不得将辅助触点、状态反馈或保护链擅自描述为接地保护、主动脱扣或必然跳闸因果。主回路、热继、反馈回路与分励线圈是不同链路；只有正文明确连接或现场测量确认时，才可把它们写成因果关系。

## I/O 点位关联查询时的协作边界

当题干涉及明确的 I/O 点位地址或点位描述，且原理图是其中一方时，必须完成本 skill 的原理图检索，并把结果用于核对另一方；这不是单独新增的功能，一个点位和多个点位都遵循同一规则：

这是不可提前结束的双侧任务：原理图 `search → pack` 只是第一侧，若资料范围为 801，完成后必须立即加载 `pd-yaskawa-ladder-graph-rg` 并用同一原始地址/描述执行梯形图 CLI；未完成另一侧不得生成最终回答，也不得用“如需进一步核对”“我可以继续查询”或“建议再查梯形图”代替必查动作。若另一侧没有对应资料，必须实际尝试后在本轮明确“未找到/不适用”，不能把查询留到下一轮。

- 用同一条用户原始问题完成一次 `search → pack`，读取命中的相关页；不得为凑命中而替换成猜测的功能词、相邻地址或其他设备。
- 从正文记录点位的原始地址、模块/通道或端子、线号、图页、跨页位置和明确功能描述；没有正文证据时保留“未找到”，不能用相似描述补齐。
- 原理图中的地址写法与其他来源不一致时，保留两种原文，只在有明确资料依据时标记“格式统一”；不得静默改写或把统一后的写法当成新的硬件事实。
- 空格、标点、大小写差异可以作为文字一致的规范化处理；近义词、缩写或语义相似只能作为候选，不能单独证明点位或物理接线关系。
- 只要原理图或梯形图一方已经取得明确 I/O 地址或描述，对资料范围内的 801 设备就必须加载 `pd-yaskawa-ladder-graph-rg` 并把该地址/描述交给另一方查询；其他设备没有对应梯形图资料时明确未找到或追问，不用其他设备替代。原理图只证明设计接线事实，不代替梯形图程序事实或现场实时状态。
- 例如用户问“查询 `IB51C5` 的原理图”：在取得原理图正文后，若设备为 801，必须立即加载梯形图 skill 并执行 `IB51C5` 的 CLI；不能只回答端子/线号后再把梯形图说成可选后续。

## 回答要求

- 只回答题干字段。线路按“来源 → 端子/触点/线号 → 去向”，PLC 保留正文原地址和解析别名；正文缺失则明确缺项，不作推断。
- 对输入无信号、反馈异常或动作异常题，若 `claim_contract.required_answer_slices` 非空，至少分别写出反馈链、执行/动作链、正文明确给出的并列控制支路，以及仍需现场确认的状态；并列支路没有明确串联依据时分开记录。
- 只要最终回答确认并引用了任一图页，就必须额外调用一次 `query_circuit_diagram(device=<设备号>, page=<图页>)` 取得真实原图；每个实际引用的跨页也应取得其原图。不得把“是否展示原图”交给模型自行决定。
- 将 `pack` 与图纸工具视作同一回答的互补证据：前者提供可核验的事实和解释，后者提供该事实对应的原图。最终回答须围绕题干自然合并两者——每个结论都应来自 `pack`，并在适合的位置嵌入图纸工具的 `markdown_content`（没有该字段时使用 `image_url`）；不得把任一工具的原始 JSON 当成答案。
- 图纸工具不会产生新的电气结论，不能抢占或改写 `pack` 的内容；`pack` 也不能因取图调用而在最终回答中消失。严禁仅输出图片、图片链接或图纸工具摘要。
- 对“原因、跳闸、动作异常”等问题，将图纸事实分为“已证实路径”“待现场确认的可能项”和“资料未确认项”，并逐项遵守 `claim_contract`。不得把主回路连接、铭牌、断路器附件或反向路径写成已证实的故障机理；它们最多构成待现场确认的检查对象。例如反馈回路只能说明状态如何回传，不能单独证明其造成主回路动作；模块、断路器或线圈更换建议必须以现场测量结果为前提。
- 当前页已识别 PLC/驱动模块的地址、通道和功能，但未给出精确型号时，只有用户要求型号、备件、替换或更换建议才补查模块配置页：用“模块标识 + 输入/输出类型 + 型号”检索并 `pack` 实际命中页；查不到时仅输出已证实的模块地址和功能，不得补写型号。
- 不要在回答末尾手写“参考文档”或“参考资料”尾注；检索结果中的 `sources`、文件名和图页由系统统一转换为回答下方的“来源（N）”面板。只引用实际使用的正文证据，不得列出未采用的候选页。
